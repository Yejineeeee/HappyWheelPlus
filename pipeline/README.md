# HappyWheel+ 데이터 파이프라인

OSM 보행 네트워크와 Copernicus 고도 자료로 도시별 접근성 점수를 계산하고, 웹이 읽는 JSON 파일(`web/public/data/<도시>/`)을 만든다.

## 설치

Python 3.11 이상.

```
cd pipeline
python -m venv .venv
.venv/Scripts/python.exe -m pip install -e ".[dev]"
```

## 명령

`pipeline/` 디렉터리에서 실행한다.

```
python -m happywheel run [--city ID ...] [--out PATH] [--cache PATH]
python -m happywheel check-size [--out PATH] [--limit-mb 2.0]
```

- `run`: 도시를 하나씩 처리한다(네트워크 수집, 고도 보정, 편의시설 수집, 결과 파일 쓰기). `--city`를 생략하면 `config/cities.yaml`의 전체 도시를 돈다. 처리한 도시만 `cities.json` 항목을 갱신하고, 실행하지 않은 도시의 기존 항목은 그대로 둔다. 알 수 없는 도시 ID는 오류 메시지와 함께 종료 코드 2. 도시 하나가 실패하면 나머지를 계속 돌리고 종료 코드 1로 끝난다.
- `check-size`: 도시 폴더마다 파일을 gzip(레벨 9)으로 압축한 크기의 합을 출력한다. 하나라도 한도(기본 2.0 MB)를 넘으면 종료 코드 1.
- 기본 출력은 `../web/public/data`, 기본 캐시는 `pipeline/.cache`(git에 넣지 않음).
- 테스트: `python -m pytest`.

## 설정(`config/cities.yaml`)

도시별 코스, 정류장, 현장 기록을 적는다. 분석 반경은 정류장 평균을 중심으로 `max(3000 m, 가장 먼 정류장 + 500 m)`로 자동 계산한다. 선택 키 `radius_m`을 적으면 자동 값 대신 그 값을 쓴다(가장 먼 정류장 + 500 m 아래로는 내리지 않는다).

캐시(`.cache/*_walk_v2.graphml`, `*_pois.json`)는 도시 ID로만 구분하므로 `radius_m`을 바꾼 뒤에는 그 도시의 두 캐시 파일을 지우고 다시 실행해야 한다.

## 알려진 한계: 지형 보정

Copernicus GLO-30은 표면 모델(DSM)이라 건물과 수목 높이가 섞여 들어가 경사가 부풀려진다. 그래서 타일을 읽은 뒤 회색조 열림(opening, 5 px 창)으로 건물·수목 같은 돌출부를 깎고, 가우시안 평활(σ 1.5)을 거쳐 쌍선형 보간으로 표본을 뽑는다. 이는 근사일 뿐이다. 교량, 고가, 폭이 5 px(약 150 m)보다 넓은 큰 건물 단지는 완전히 제거되지 않거나 반대로 실제 언덕 끝이 깎일 수 있고, 수치는 전용 지형 모델(DTM)의 대체가 아니다. 경사 관련 점수는 이 한계를 감안해서 읽어야 한다.

### 한도 조정

런던(2.18 MB)과 파리(2.24 MB)가 기본 반경 3000 m에서 gzip 한도 2.0 MB를 넘어 `radius_m`을 설정했다.

| 도시 | 반경 | gzip | 간선 |
|---|---|---|---|
| 런던 | 3000 m -> 2700 m (가장 먼 정류장 2173 m + 500 m = 2673 m) | 2.18 -> 1.85 MB | 58600 -> 49837 |
| 파리 | 3000 m -> 1800 m (가장 먼 정류장 1258 m + 500 m = 1758 m) | 2.24 -> 0.85 MB | 60638 -> 23287 |

### 상식 점검

- 베네치아: 두 코스 모두 reachable=true이고 최단/접근성 모두 계단 0, 즉 steps_avoided=0이다. 기대한 steps_avoided > 0 또는 reachable=false는 나오지 않았다. 최단 경로가 계단을 거의 안 지나는 것으로 잡혀 OSM의 베네치아 다리 계단 태그가 충분히 반영됐는지 확인이 필요하다. 접근성 경로는 최단 대비 38~56 m 우회하고 최대 경사가 7.5%에서 4.9%로 줄어드는 점은 맞다.
- 로마 포로 로마노 코스: 자갈길 cobble_m 784.6 m(최단) / 401.9 m(접근성). 런던 코스는 8.5 m / 4.2 m(둘 다 접근성 경로가 없어 최단 경로 값만 있음)이므로 로마가 런던보다 훨씬 크다. 기대와 일치.
- 런던: 두 코스 모두 접근성 경로가 reachable=false다. 반경을 3000 m로 되돌려도 같은 결과여서 반경 축소 때문이 아니다. 현재 점수·차단 규칙에서 나온 결과로 보이며 원인 조사가 필요하다(`blocked_at`이 각각 테이트 모던과 웨스트민스터 브리지 정류장).
- 파리·루체른 등 다른 도시는 접근성 경로가 계단을 0으로 만들고 우회 거리가 짧아 합리적이다.
